## Current Architecture

### Core Runtime Model

OpenALP currently uses a Python reference runtime implementing a deterministic, single-threaded stack machine.

Key runtime properties:

1. bounded execution via max steps
2. immutable instruction stream after parse
3. append-only output stream
4. no hidden external state in the reference VM

### Bundle Model

Current bundle variants:

1. `.alpp.json` for readable agent exchange
2. `.alppb` for compact machine-native transport

Bundle content currently includes:

1. encoded module bytes
2. hello payload
3. checksum manifest
4. signature manifest
5. key hint metadata

### Versioning Model

At handoff:

1. module format version is `1`
2. protocol version `0.2` is active
3. protocol version `0.1` is deprecated but accepted
